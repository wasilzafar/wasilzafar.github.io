Core Learning Path

The required 18-part path begins with integer intuition, divisibility, proofs, GCD, primes, and sieves; develops modular arithmetic, CRT, factorization, arithmetic functions, combinatorics, continued fractions, residues, and discrete logarithms; then advances to recurrences, FFT/NTT, finite fields, fast arithmetic, elliptic curves, and number-theoretic data structures. Each part includes derivations, implementation guidance, applications, case studies, and exercises.
