Intuition, Vocabulary and Foundations

A recurrence laboratory treats a sequence as both observations and algebra. From 0, 1, 1, 2, 3, 5, 8, Berlekamp–Massey can propose $(s_n=s_{n-1}+s_{n-2})$; held-out samples then test whether that proposal predicts rather than merely fits. The same rule has a companion matrix, characteristic polynomial $(x^2-x-1)$, and rational generating function.

Convolution is polynomial multiplication: [1,2,3] convolved with [4,5] is [4,13,22,15]. Kitamasa also multiplies polynomials and reduces them modulo a characteristic polynomial, so faster convolution can accelerate high-order recurrence evaluation. Formal power series connect both views through coefficient identities without requiring numerical convergence.

Every representation must describe the same sequence: samples, recurrence coefficients, matrix state, characteristic polynomial, and generating function. An inferred rule remains a hypothesis until it reproduces training and held-out terms over the stated field.

Step-by-Step Derivations and Algorithms

Berlekamp–Massey maintains a connection polynomial annihilating the processed prefix. A discrepancy of zero preserves it; a nonzero discrepancy shifts and scales an earlier correction using a field inverse. It returns a shortest recurrence for $(m)$ samples in $(O(m^2))$ field operations.

For recurrence coefficients $(c_1,\ldots,c_d)$, reduce $(x^n)$ modulo $(Q(x)=x^d-c_1x^{d-1}-\cdots-c_d)$. The remainder has degree below $(d)$, and its coefficients form weights for the initial terms. Binary polynomial exponentiation gives Kitamasa complexity $(O(d^2\log n))$ with naive multiplication. Companion-matrix exponentiation gives $(O(d^3\log n))$, usually slower for one scalar but valuable as an independent oracle. Naive convolution is quadratic; FFT and NTT reduce large products to $(O(L\log L))$, with rounding constraints for FFT and root-of-unity constraints for NTT.

Berlekamp–Massey is minimal only over a field and for the supplied prefix; held-out validation sets the empirical boundary. Kitamasa and matrices preserve the same recurrence state, while naive convolution costs $(O(d^2))$ and NTT costs $(O(L\log L))$; practical crossover points must be measured.

Implementation, Complexity and Engineering

The executable laboratory below works modulo $(998244353)$. It infers recurrences, evaluates them with Kitamasa, multiplies with naive or iterative NTT backends, and exposes the selection threshold. Deterministic randomized tests compare independent implementations; timing is reported rather than asserted because hardware and runtimes change crossover points.

from random import Random
from time import perf_counter

MOD = 998244353
ROOT = 3


def berlekamp_massey(s, mod=MOD):
    c, b = [1], [1]
    length, shift, last = 0, 1, 1
    for n in range(len(s)):
        discrepancy = s[n] % mod
        for i in range(1, length + 1):
            discrepancy = (discrepancy + c[i] * s[n - i]) % mod
        if discrepancy == 0:
            shift += 1
            continue
        old = c[:]
        scale = discrepancy * pow(last, mod - 2, mod) % mod
        if len(c) < len(b) + shift:
            c += [0] * (len(b) + shift - len(c))
        for i, value in enumerate(b):
            c[i + shift] = (c[i + shift] - scale * value) % mod
        if 2 * length <= n:
            length = n + 1 - length
            b, last, shift = old, discrepancy, 1
        else:
            shift += 1
    return [(-c[i]) % mod for i in range(1, length + 1)]


def combine(a, b, rec, mod=MOD):
    d = len(rec)
    product = [0] * (2 * d - 1)
    for i, x in enumerate(a):
        for j, y in enumerate(b):
            product[i + j] = (product[i + j] + x * y) % mod
    for degree in range(2 * d - 2, d - 1, -1):
        for offset, coefficient in enumerate(rec, 1):
            product[degree - offset] = (product[degree - offset] + product[degree] * coefficient) % mod
    return product[:d]


def kitamasa(initial, rec, index, mod=MOD):
    if index < 0 or not rec or len(initial) < len(rec):
        raise ValueError("invalid recurrence state or index")
    if index < len(rec):
        return initial[index] % mod
    d = len(rec)
    result = [1] + [0] * (d - 1)
    base = [rec[0] % mod] if d == 1 else [0, 1] + [0] * (d - 2)
    while index:
        if index & 1:
            result = combine(result, base, rec, mod)
        base = combine(base, base, rec, mod)
        index >>= 1
    return sum(result[i] * initial[i] for i in range(d)) % mod


def naive_convolution(a, b, mod=MOD):
    if not a or not b:
        return []
    result = [0] * (len(a) + len(b) - 1)
    for i, x in enumerate(a):
        for j, y in enumerate(b):
            result[i + j] = (result[i + j] + x * y) % mod
    return result


def ntt(a, invert, mod=MOD):
    n = len(a)
    if not n or n & (n - 1) or (mod - 1) % n:
        raise ValueError("unsupported NTT length")
    j = 0
    for i in range(1, n):
        bit = n >> 1
        while j & bit:
            j ^= bit
            bit >>= 1
        j ^= bit
        if i < j:
            a[i], a[j] = a[j], a[i]
    length = 2
    while length <= n:
        root = pow(ROOT, (mod - 1) // length, mod)
        if invert:
            root = pow(root, mod - 2, mod)
        for start in range(0, n, length):
            factor = 1
            for offset in range(length // 2):
                even = a[start + offset]
                odd = a[start + offset + length // 2] * factor % mod
                a[start + offset] = (even + odd) % mod
                a[start + offset + length // 2] = (even - odd) % mod
                factor = factor * root % mod
        length *= 2
    if invert:
        inverse = pow(n, mod - 2, mod)
        for i in range(n):
            a[i] = a[i] * inverse % mod


def ntt_convolution(a, b, mod=MOD):
    if not a or not b:
        return []
    output = len(a) + len(b) - 1
    size = 1
    while size < output:
        size *= 2
    left = [x % mod for x in a] + [0] * (size - len(a))
    right = [x % mod for x in b] + [0] * (size - len(b))
    ntt(left, False, mod)
    ntt(right, False, mod)
    left = [x * y % mod for x, y in zip(left, right)]
    ntt(left, True, mod)
    return left[:output]


def convolution(a, b, threshold=64):
    if threshold < 1:
        raise ValueError("threshold must be positive")
    if min(len(a), len(b)) <= threshold:
        return naive_convolution(a, b), "naive"
    return ntt_convolution(a, b), "ntt"


fibonacci = [0, 1]
for _ in range(2, 80):
    fibonacci.append((fibonacci[-1] + fibonacci[-2]) % MOD)
recurrence = berlekamp_massey(fibonacci[:30])
assert recurrence == [1, 1]
for index, expected in enumerate(fibonacci):
    assert kitamasa([0, 1], recurrence, index) == expected

rng = Random(11)
for n in range(1, 24):
    for m in range(1, 24):
        a = [rng.randrange(MOD) for _ in range(n)]
        b = [rng.randrange(MOD) for _ in range(m)]
        assert ntt_convolution(a, b) == naive_convolution(a, b)

assert naive_convolution([1, 2, 3], [4, 5]) == [4, 13, 22, 15]
start = perf_counter()
trace = kitamasa([0, 1], recurrence, 1_000_000)
elapsed = perf_counter() - start
print("trace:", recurrence, trace, elapsed)
print("all tests passed")

Applications, Case Studies and Exercises

An approachable experiment infers Fibonacci's recurrence, validates it on held-out samples, and compares distant terms with an independent matrix implementation. A production laboratory groups sampled sequences by field, preserves training and validation splits, benchmarks polynomial backends across orders, and records machine, seed, modulus, repetitions, warm-up policy, and raw timings.

Exercises should progress from translating a recurrence into a characteristic polynomial, through proving Kitamasa reduction, to adding arbitrary-modulus convolution. Debugging targets include inadequate samples, reversed coefficients, unsupported NTT lengths, composite-modulus inverses, and FFT rounding.

Verify every coefficient and report the first size where NTT has a lower median. Do not hard-code the result from another machine.

Deliverable. Build infer, evaluate, convolve, and benchmark commands emitting modulus, seed, backend, threshold, input sizes, elapsed time, and verification status. Pass tests for zero sequences, order one, insufficient state, empty polynomials, negative coefficients, invalid thresholds, and unsupported transform lengths.

Use iteration nearby, matrices as a transparent oracle, Kitamasa for distant scalar terms, naive convolution below a measured threshold, and FFT or NTT only inside their numeric domains. A prefix fit is not a proven law, and an asymptotic advantage is not a benchmark result; preserve independent representations for trustworthy cross-checks.
