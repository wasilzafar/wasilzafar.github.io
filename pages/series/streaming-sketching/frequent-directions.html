Compressing a Matrix Row by Row

Let $A\in\mathbb R^{n\times d}$ arrive one row at a time. Frequent Directions (FD) retains only an $\ell\times d$ matrix $B$. Think of compressing a stack of measurements whenever it fills: singular directions are found, the same squared amount is shaved from each, and the newly zero direction becomes space for the next row.

For every unit vector $x$, $\lVert Ax\rVert_2^2=x^\top A^\top Ax$ is the full directional energy and $\lVert Bx\rVert_2^2$ is its sketch estimate. FD deterministically controls their difference. With $\ell=2$ and rows $(3,0),(0,1)$, squared singular values are $(9,1)$. Subtracting $\delta=1$ gives $(8,0)$, so the covariance loss is exactly $\operatorname{diag}(1,1)$.

Singular-value shrinkage subtracts a shared threshold from squared singular values. Covariance error means $A^\top A-B^\top B$. Low-rank tail energy is $\lVert A-A_k\rVert_F^2$. Mergeability means sketches of partitions can be stacked and sketched again. Determinism removes random failure probability, not floating-point error.

Frequent Directions preserves directional second-moment energy by uniformly shrinking squared singular values. It is a covariance sketch—not a row sample, deletion-capable summary, centering method, or nonlinear statistic.

Warm-up

Compressing a Matrix Row by Row

For $A=\operatorname{diag}(3,1)$ and $\ell=2$: compute $A^\top A=\operatorname{diag}(9,1)$; set $\delta=1$; shrink to $(8,0)$; form $B=\operatorname{diag}(\sqrt8,0)$; verify $A^\top A-B^\top B=I$. For every unit $x$, lost energy equals $1$. Reflection: why is a shared squared threshold essential?

Shrinkage, Singular Values and the Covariance Invariant

When full, write $B=U\Sigma V^\top$, set $\delta=\sigma_\ell^2$, and update \[ B\leftarrow\sqrt{\max(\Sigma^2-\delta I,0)}\,V^\top. \] For every unit $x$, one compression loses at most $\delta$, because expansion in the right-singular basis gives a convex combination of losses no larger than $\delta$. Frobenius energy falls by at least $\ell\delta$. Summing thresholds as $\Delta=\sum_t\delta_t$ yields \[ 0\le\lVert Ax\rVert_2^2-\lVert Bx\rVert_2^2\le\Delta,\qquad \ell\Delta\le\lVert A\rVert_F^2-\lVert B\rVert_F^2. \] Charging the top $k$ directions proves, for every $k$ strictly smaller than $\ell$, \[ \Delta\le\frac{\lVert A-A_k\rVert_F^2}{\ell-k}. \] Negative rows do not delete old rows: covariance is quadratic, so $a$ and $-a$ both add $aa^\top$. Uncentered input estimates second moments, not centered covariance.

For every unit $x$ and every $k$ strictly smaller than $\ell$, FD guarantees $0\le\lVert Ax\rVert_2^2-\lVert Bx\rVert_2^2\le\lVert A-A_k\rVert_F^2/(\ell-k)$. It is deterministic and one-sided, but an undersized sketch cannot overcome a large spectral tail.

Spectral Error from Accumulated Shrinkage

Because the inequality holds for every unit vector, \[ \lVert A^\top A-B^\top B\rVert_2\le\Delta. \] Thus FD never invents covariance energy in exact arithmetic. The top right-singular vectors of $B$ support streaming PCA, while tail energy determines the meaningful sketch size.

Worked Example

Spectral Error from Accumulated Shrinkage

For squared singular values $(16,12,4)$ and $\ell=3$, shrink to $(12,8,0)$. Frobenius energy falls from $32$ to $20$, exactly $\ell\delta=12$; every directional loss is at most $4$; and the covariance-difference eigenvalues are $(4,4,4)$. Perturb by subtracting from singular values instead of squared values: uniform covariance loss disappears.

import numpy as np

class FrequentDirections:
    def __init__(self, ell, d):
        if ell < 2 or d < 1:
            raise ValueError("invalid dimensions")
        self.ell, self.d = ell, d
        self.B = np.zeros((ell, d))
        self.used = 0
        self.total_delta = 0.0

    def append(self, row):
        row = np.asarray(row, dtype=float)
        if row.shape != (self.d,) or not np.all(np.isfinite(row)):
            raise ValueError("invalid row")
        if self.used == self.ell:
            self.compress()
        self.B[self.used] = row
        self.used += 1

    def compress(self):
        _, s, vt = np.linalg.svd(self.B, full_matrices=False)
        delta = s[-1] ** 2
        shrunk = np.sqrt(np.maximum(s ** 2 - delta, 0))
        self.B = shrunk[:, None] * vt
        self.total_delta += delta
        self.used = int(np.count_nonzero(shrunk > 1e-12))

    def finish(self):
        if self.used == self.ell:
            self.compress()
        return self.B.copy()

rng = np.random.default_rng(12)
A = rng.normal(size=(60, 8))
A[:, 0] *= 4
fd = FrequentDirections(5, 8)
for row in A:
    fd.append(row)
B = fd.finish()
loss = A.T @ A - B.T @ B
eigs = np.linalg.eigvalsh(loss)
assert eigs[0] > -1e-8
assert eigs[-1] <= fd.total_delta + 1e-8
assert np.linalg.norm(A, "fro")**2 - np.linalg.norm(B, "fro")**2 >= 5*fd.total_delta - 1e-7

zero = FrequentDirections(3, 4)
for _ in range(7):
    zero.append(np.zeros(4))
assert np.allclose(zero.finish(), 0)
try:
    fd.append([1, 2])
    raise AssertionError("invalid row accepted")
except ValueError:
    pass

delete_case = np.array([[2.0, 0.0], [-2.0, 0.0]])
assert np.allclose(delete_case.T @ delete_case, np.diag([8.0, 0.0]))
print("spectral error:", round(float(eigs[-1]), 6))
print("accumulated shrinkage:", round(fd.total_delta, 6))

Streaming PCA and Regression

Teaching: stream a two-direction matrix and compare exact and sketched eigenvalues. Production: sketch centered telemetry rows, merge only compatible shards, and refresh principal components from $B$. Regression requires a theorem matching the response-aware objective; covariance preservation alone is not a universal regression guarantee. Reject FD for row deletions or lifetime sketches that must forget old data.

Invalidating evidence includes spectral error above the tail budget, materially negative covariance-loss eigenvalues, unstable principal angles, poor held-out reconstruction, incompatible feature dictionaries, overflow, or merge-tree sensitivity beyond tolerance.

Practice: Implement and Test Frequent Directions

Use rows $(3,0,0),(0,2,0),(0,0,1),(1,1,0)$, $ell=3$, and $k=1$. Trace every buffer, singular value, threshold, and compressed matrix; compute exact and sketched covariance; verify positive-semidefinite loss and the tail bound; debug subtracting from singular values, choosing the largest threshold, and overwriting a live row; test zeros, rank deficiency, repeats, nonfinite values, and dimension mismatch; merge two partition sketches and compare guarantees; then benchmark batched compression. Rubric: 25% shrinkage, 20% invariant, 20% bound, 15% tests, 10% merge reasoning, 10% deployment judgment.

Checklist: define centered second-moment semantics; choose $k$ smaller than $\ell$ from measured tail energy; shrink squared singular values; track $\Delta$; verify positive-semidefinite covariance loss; version schemas and merge metadata; benchmark SVD cadence; and reject deletion, forgetting, or response-aware claims outside the model.
