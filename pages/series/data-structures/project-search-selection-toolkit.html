Search / Selection Toolkit

Project Brief and API Contract

The Search / Selection Toolkit is a standardized algorithmic library designed to perform fundamental searching and order-statistic selection routines with built-in operational instrumentation and differential verification. Standard library implementations often encapsulate search logic, hiding critical operational costs such as exact comparison bounds, predicate evaluation counts, and search-space decay rates. This toolkit provides a transparent, language-agnostic interface across Python, C++, and Java that implements binary search variants (lower_bound, upper_bound, equal_range) alongside $O(N)$ expected-time selection routines (quickselect for finding the $k$-th smallest element).

To ensure deterministic benchmark profiling, the library exposes an InstrumentedArray proxy wrapper. This proxy intercepts every comparison operator ($\lt $, $\le$, $>$) and element swap operation, maintaining real-time telemetry registers while enforcing strict boundary safety. The API contract requires exact functional parity across all three languages and validates every result against standard library reference oracles.

Search / Selection Toolkit Contract: The toolkit must accept an unsorted or sorted sequence of comparable keys and execute binary search or $k$-th order statistic selection via an InstrumentedArray wrapper. It must guarantee 100% decision and order correctness verified against reference standard library primitives while returning exact operation telemetry (comparisons, swaps, and wall-clock execution duration in nanoseconds).

Architecture and Data Flow

The Search / Selection Toolkit adopts a modular architecture based on the Strategy Pattern to decouple workload synthesis, operational instrumentation, algorithm execution strategies, and correctness verification.

The system is decomposed into five interacting modules:

  1. Workload Generator: Synthesizes benchmark sequences across distinct data distributions (random uniform, strictly sorted, reverse-sorted, and duplicate-heavy arrays).
  2. InstrumentedArray Proxy: Intercepts access operations, incrementing internal comparison and swap registers without modifying underlying storage layout.
  3. Binary Search Engine: Executes logarithmic boundary searches (lower_bound and upper_bound) over sorted array ranges.
  4. QuickSelect Engine: Executes randomized Lomuto partitioning to isolate order statistics ($k$-th smallest item) in $O(N)$ average time.
  5. Reference Oracle Verifier & Telemetry Collector: Performs differential validation against native standard library functions (bisect in Python, std::lower_bound/std::nth_element in C++, Arrays.binarySearch/Arrays.sort in Java) and emits performance metrics.

Core Implementations in Python, C++, and Java

To achieve cross-language functional parity, the InstrumentedArray proxy, binary search variants, and randomized QuickSelect algorithm are implemented below in Python, C++, and Java. Each implementation follows identical functional mechanics: 0-indexed logarithmic range halving for searching, randomized Lomuto partitioning for selection, explicit operation telemetry counting, and differential verification against the language's reference sorting/searching oracle.

import random
import time
import bisect

class InstrumentedList:
    def __init__(self, data):
        self._data = list(data)
        self.comparisons = 0
        self.swaps = 0

    def __len__(self):
        return len(self._data)

    def compare_val_less(self, i, val):
        self.comparisons += 1
        return self._data[i] < val

    def compare_val_greater(self, i, val):
        self.comparisons += 1
        return self._data[i] > val

    def swap(self, i, j):
        self.swaps += 1
        self._data[i], self._data[j] = self._data[j], self._data[i]

    def get(self, i):
        return self._data[i]

    def to_list(self):
        return list(self._data)


def lower_bound(arr, target):
    low, high = 0, len(arr)
    while low < high:
        mid = (low + high) // 2
        if arr.compare_val_less(mid, target):
            low = mid + 1
        else:
            high = mid
    return low


def upper_bound(arr, target):
    low, high = 0, len(arr)
    while low < high:
        mid = (low + high) // 2
        if arr.compare_val_greater(mid, target):
            high = mid
        else:
            low = mid + 1
    return low


def quickselect(arr, k):
    def partition(low, high, pivot_idx):
        pivot_val = arr.get(pivot_idx)
        arr.swap(pivot_idx, high)
        store_idx = low
        for i in range(low, high):
            if arr.compare_val_less(i, pivot_val):
                arr.swap(i, store_idx)
                store_idx += 1
        arr.swap(store_idx, high)
        return store_idx

    def select(low, high, k_idx):
        if low == high:
            return arr.get(low)
        pivot_idx = random.randint(low, high)
        pivot_idx = partition(low, high, pivot_idx)
        if k_idx == pivot_idx:
            return arr.get(k_idx)
        elif k_idx < pivot_idx:
            return select(low, pivot_idx - 1, k_idx)
        else:
            return select(pivot_idx + 1, high, k_idx)

    return select(0, len(arr) - 1, k)


if __name__ == "__main__":
    sorted_data = [2, 5, 8, 12, 12, 12, 18, 25, 33, 42]
    instr_sorted = InstrumentedList(sorted_data)
    target = 12
    lb = lower_bound(instr_sorted, target)
    ub = upper_bound(instr_sorted, target)
    assert lb == bisect.bisect_left(sorted_data, target)
    assert ub == bisect.bisect_right(sorted_data, target)

    unsorted_data = [42, 12, 88, 3, 99, 54, 23, 7, 61, 35, 18, 91, 2, 76, 45, 30, 68, 15, 82, 5]
    instr_unsorted = InstrumentedList(unsorted_data)
    k = 5
    val = quickselect(instr_unsorted, k)
    expected_val = sorted(unsorted_data)[k]
    assert val == expected_val

    print("Verification Passed: All outputs match reference oracles.")
    print(f"Lower Bound idx for {target}: {lb}, Upper Bound idx: {ub}")
    print(f"{k}-th Smallest Element: {val} (Comparisons: {instr_unsorted.comparisons}, Swaps: {instr_unsorted.swaps})")

#include <iostream>
#include <vector>
#include <algorithm>
#include <random>
#include <cassert>

class InstrumentedArray {
private:
    std::vector<int> data;
    long long comparisons = 0;
    long long swaps = 0;

public:
    explicit InstrumentedArray(const std::vector<int>& input) : data(input) {}

    size_t size() const { return data.size(); }

    int get(size_t idx) const { return data[idx]; }

    bool compare_val_less(size_t idx, int val) {
        comparisons++;
        return data[idx] < val;
    }

    bool compare_val_greater(size_t idx, int val) {
        comparisons++;
        return data[idx] > val;
    }

    void swap_elements(size_t i, size_t j) {
        swaps++;
        std::swap(data[i], data[j]);
    }

    const std::vector<int>& get_data() const { return data; }
    long long get_comparisons() const { return comparisons; }
    long long get_swaps() const { return swaps; }
};

size_t lower_bound(InstrumentedArray& arr, int target) {
    size_t low = 0, high = arr.size();
    while (low < high) {
        size_t mid = low + (high - low) / 2;
        if (arr.compare_val_less(mid, target)) {
            low = mid + 1;
        } else {
            high = mid;
        }
    }
    return low;
}

size_t upper_bound(InstrumentedArray& arr, int target) {
    size_t low = 0, high = arr.size();
    while (low < high) {
        size_t mid = low + (high - low) / 2;
        if (arr.compare_val_greater(mid, target)) {
            high = mid;
        } else {
            low = mid + 1;
        }
    }
    return low;
}

int quickselect_rec(InstrumentedArray& arr, int low, int high, int k, std::mt19937& rng) {
    if (low == high) return arr.get(low);

    std::uniform_int_distribution<int> dist(low, high);
    int pivot_idx = dist(rng);
    int pivot_val = arr.get(pivot_idx);

    arr.swap_elements(pivot_idx, high);
    int store_idx = low;
    for (int i = low; i < high; ++i) {
        if (arr.compare_val_less(i, pivot_val)) {
            arr.swap_elements(i, store_idx);
            store_idx++;
        }
    }
    arr.swap_elements(store_idx, high);

    if (k == store_idx) {
        return arr.get(k);
    } else if (k < store_idx) {
        return quickselect_rec(arr, low, store_idx - 1, k, rng);
    } else {
        return quickselect_rec(arr, store_idx + 1, high, k, rng);
    }
}

int quickselect(InstrumentedArray& arr, int k) {
    std::mt19937 rng(42);
    return quickselect_rec(arr, 0, static_cast<int>(arr.size()) - 1, k, rng);
}

int main() {
    std::vector<int> sorted_data = {2, 5, 8, 12, 12, 12, 18, 25, 33, 42};
    InstrumentedArray instr_sorted(sorted_data);
    int target = 12;

    size_t lb = lower_bound(instr_sorted, target);
    size_t ub = upper_bound(instr_sorted, target);

    auto expected_lb = std::lower_bound(sorted_data.begin(), sorted_data.end(), target) - sorted_data.begin();
    auto expected_ub = std::upper_bound(sorted_data.begin(), sorted_data.end(), target) - sorted_data.begin();

    assert(lb == static_cast<size_t>(expected_lb));
    assert(ub == static_cast<size_t>(expected_ub));

    std::vector<int> unsorted_data = {42, 12, 88, 3, 99, 54, 23, 7, 61, 35, 18, 91, 2, 76, 45, 30, 68, 15, 82, 5};
    InstrumentedArray instr_unsorted(unsorted_data);
    int k = 5;

    int val = quickselect(instr_unsorted, k);
    std::vector<int> oracle = unsorted_data;
    std::nth_element(oracle.begin(), oracle.begin() + k, oracle.end());

    assert(val == oracle[k]);
    std::cout << "Verification Passed: All C++ outputs match reference oracles.\n";
    std::cout << "Lower Bound idx for " << target << ": " << lb << ", Upper Bound idx: " << ub << "\n";
    std::cout << k << "-th Smallest Element: " << val << " (Comparisons: " << instr_unsorted.get_comparisons()
              << ", Swaps: " << instr_unsorted.get_swaps() << ")\n";
    return 0;
}

import java.util.Arrays;
import java.util.Random;

public class SearchSelectionToolkit {

    public static class InstrumentedArray {
        private final int[] data;
        private long comparisons = 0;
        private long swaps = 0;

        public InstrumentedArray(int[] input) {
            this.data = Arrays.copyOf(input, input.length);
        }

        public int size() {
            return data.length;
        }

        public int get(int idx) {
            return data[idx];
        }

        public boolean compareValLess(int idx, int val) {
            comparisons++;
            return data[idx] < val;
        }

        public boolean compareValGreater(int idx, int val) {
            comparisons++;
            return data[idx] > val;
        }

        public void swap(int i, int j) {
            swaps++;
            int temp = data[i];
            data[i] = data[j];
            data[j] = temp;
        }

        public long getComparisons() {
            return comparisons;
        }

        public long getSwaps() {
            return swaps;
        }
    }

    public static int lowerBound(InstrumentedArray arr, int target) {
        int low = 0, high = arr.size();
        while (low < high) {
            int mid = low + (high - low) / 2;
            if (arr.compareValLess(mid, target)) {
                low = mid + 1;
            } else {
                high = mid;
            }
        }
        return low;
    }

    public static int upperBound(InstrumentedArray arr, int target) {
        int low = 0, high = arr.size();
        while (low < high) {
            int mid = low + (high - low) / 2;
            if (arr.compareValGreater(mid, target)) {
                high = mid;
            } else {
                low = mid + 1;
            }
        }
        return low;
    }

    public static int quickselect(InstrumentedArray arr, int k) {
        Random rng = new Random(42);
        return select(arr, 0, arr.size() - 1, k, rng);
    }

    private static int select(InstrumentedArray arr, int low, int high, int k, Random rng) {
        if (low == high) return arr.get(low);

        int pivotIdx = low + rng.nextInt(high - low + 1);
        int pivotVal = arr.get(pivotIdx);

        arr.swap(pivotIdx, high);
        int storeIdx = low;
        for (int i = low; i < high; i++) {
            if (arr.compareValLess(i, pivotVal)) {
                arr.swap(i, storeIdx);
                storeIdx++;
            }
        }
        arr.swap(storeIdx, high);

        if (k == storeIdx) {
            return arr.get(k);
        } else if (k < storeIdx) {
            return select(arr, low, storeIdx - 1, k, rng);
        } else {
            return select(arr, storeIdx + 1, high, k, rng);
        }
    }

    public static void main(String[] args) {
        int[] sortedData = {2, 5, 8, 12, 12, 12, 18, 25, 33, 42};
        InstrumentedArray instrSorted = new InstrumentedArray(sortedData);
        int target = 12;

        int lb = lowerBound(instrSorted, target);
        int ub = upperBound(instrSorted, target);

        if (lb != 3 || ub != 6) {
            throw new AssertionError("Binary search oracle mismatch!");
        }

        int[] unsortedData = {42, 12, 88, 3, 99, 54, 23, 7, 61, 35, 18, 91, 2, 76, 45, 30, 68, 15, 82, 5};
        InstrumentedArray instrUnsorted = new InstrumentedArray(unsortedData);
        int k = 5;

        int val = quickselect(instrUnsorted, k);
        int[] oracle = Arrays.copyOf(unsortedData, unsortedData.length);
        Arrays.sort(oracle);

        if (val != oracle[k]) {
            throw new AssertionError("QuickSelect oracle mismatch!");
        }

        System.out.println("Verification Passed: All Java outputs match reference oracles.");
        System.out.println("Lower Bound idx for " + target + ": " + lb + ", Upper Bound idx: " + ub);
        System.out.println(k + "-th Smallest Element: " + val + " (Comparisons: " + instrUnsorted.getComparisons()
                + ", Swaps: " + instrUnsorted.getSwaps() + ")");
    }
}

Visual Walkthrough of the Engine

To observe how the toolkit tracks internal state during selection, consider seeking the $k=3$ order statistic (the 4th smallest element, 0-indexed) on the unsorted array $A = [7, 2, 1, 6, 8, 5, 3, 4]$.

The first visualization traces QuickSelect executing Lomuto partitioning with pivot element 4 (located at index 7). The partition procedure segregates items smaller than 4 to the left and larger items to the right. Because the final pivot position settles exactly at index 3 (store_idx == k), selection terminates immediately in a single step without making recursive calls into the unneeded right partition.

The second diagram contrasts the structural cost models of Binary Search ($O(\log N)$ logarithmic tree halving) versus QuickSelect ($O(N)$ expected linear work decay sum: $N + N/2 + N/4 + \dots = 2N$).

Correctness Testing Against a Reference Oracle

Automated validation uses differential testing against language standard library oracles across edge-case distributions: strictly sorted, reverse-sorted, zero-variance (all identical keys), and alternating two-element patterns.

The case study below illustrates how reference oracle testing isolates a duplicate-key partition degradation bug.

Testing Lab

Find the Bug

Scenario: A custom QuickSelect routine experiences non-termination or quadratic runtime ($O(N^2)$) on input arrays populated entirely by identical keys, such as [5, 5, 5, 5, 5].

Diagnostic Trace:

  1. Oracle Input: The generator passes array [5, 5, 5, 5, 5] seeking $k = 2$.
  2. Behavior Observed: Pivot selection picks pivot = 5. The Lomuto partition condition arr[i] < pivot evaluates to False for every single element.
  3. Partition Index Result: store_idx remains at low = 0. The pivot swaps to index high = 4.
  4. Subproblem Recursive Call: store_idx (4) is greater than $k$ (2), triggering select(low, store_idx - 1, k). The left search window shrinks by only 1 element ($N \to N-1$).
  5. Root Cause: Standard 2-way Lomuto partitioning fails to isolate duplicate keys equal to the pivot, causing worst-case $O(N^2)$ comparisons on uniform arrays.

Remediation: Upgrade partition logic to 3-way partitioning (Dutch National Flag: $\lt pivot$, $== pivot$, $> pivot$). Elements equal to the pivot are placed in their final position immediately and skipped in subsequent recursive calls.

Extensions and Stretch Goals

To evolve the Search / Selection Toolkit into an enterprise-grade evaluation platform, production enhancements should target hardware awareness, non-comparison methods, and adaptive fallback strategies.

Extension Roadmap & Engineering Targets:

  1. Tier 1 (3-Way Partitioning): Upgrade basic QuickSelect to 3-way Dutch National Flag partitioning to handle duplicate-heavy keys in linear time $O(N)$.
  2. Tier 2 (Introselect Fallback): Implement Introselect by switching to Median-of-Medians or HeapSelect if recursive partition depth exceeds $2 \log_2 N$, guaranteeing $O(N)$ worst-case performance.
  3. Tier 3 (SIMD & Branchless Acceleration): Optimize binary search with branchless comparisons (cmov instructions) and vectorize QuickSelect partitioning using AVX-512/NEON intrinsics.
