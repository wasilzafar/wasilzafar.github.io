Project Brief and API Contract

The Dynamic Programming Workbook is an algorithmic suite and benchmark laboratory designed to solve core optimization and combinatorial problems across four distinct execution paradigms: Naive Recurrence, Top-Down Memoization, Bottom-Up Tabulation, and Space-Optimized Tabulation. Dynamic Programming (DP) is the foundational technique for problems exhibiting overlapping subproblems and optimal substructure (e.g., 0/1 Knapsack, Longest Common Subsequence, Edit Distance, and Matrix Chain Multiplication). However, transitioning a mathematical recurrence into production-grade code requires evaluating trade-offs between call-stack recursion overhead, state-table memory consumption, cache locality, and decision-path reconstruction.

This laboratory isolates these execution paradigms behind a unified DPProblemEngine contract. Every solver instance processes problem instances (e.g., item weights, values, sequence strings, or capacity bounds), computes exact optimal objective values, logs granular runtime telemetry (subproblem state evaluations, memoization hits, array writes), and provides complete decision-path reconstruction. Differential testing against exhaustive recursion oracles ensures 100% behavioral equivalence across all four execution strategies.

DP Workbook Contract: Every DP solver engine must implement four distinct operational strategies—Naive Recursion, Top-Down Memoization, Bottom-Up Tabulation, and Space-Optimized Tabulation—for every problem class. All four solvers must yield identical objective values and decision paths, while maintaining strict compliance with theoretical time and memory complexities verified via automated differential testing.

Architecture and Data Flow

The Dynamic Programming Workbook adopts a strategy-pattern architecture that decouples problem representation from state evaluation, memory layout, telemetry tracking, and correctness verification.

The architecture comprises five principal modules:

  1. Problem Input Synthesizer: Generates problem instances, including 0/1 Knapsack datasets, string pairs for sequence alignment, and synthetic adversarial inputs designed to trigger call-stack overflow or cache thrashing.
  2. DP Workbook Gateway Interface: Exposes the polymorphic contract (solve_recursive, solve_memoized, solve_tabulated, solve_space_optimized, reconstruct_path).
  3. Core Strategy Solvers: Implements state transitions across four execution paradigms: Naive Recurrence Engine: Evaluates mathematical recurrence branches directly ($O(2^N)$ call tree). Top-Down Memoization Engine: Wraps recursive calls with an $O(N \cdot W)$ state table or hash map cache to prune redundant subproblems. Bottom-Up 2D Tabulated Engine: Iteratively populates an explicit $N \times W$ DP table in topological order, guaranteeing $O(1)$ state lookups and straightforward path reconstruction. Space-Optimized 1D Buffer Engine: Compress 2D state matrices into 1D rolling buffers ($O(W)$ space) by exploiting single-step temporal state dependencies.
  1. State Auditor & Path Reconstructor: Verifies state transition invariants during table fills and backtracks through table state boundaries to extract optimal decision sequences.
  2. Reference Oracle & Telemetry Collector: Audits objective results against exhaustive brute-force search and records total subproblem evaluations, table writes, and execution runtimes.

Core Implementations in Python, C++, and Java

The complete, runnable implementations below demonstrate a multi-paradigm 0/1 Knapsack DP Engine across Python, C++, and Java. Each language implementation includes all four solver strategies (Naive Recursion, Top-Down Memoization, Bottom-Up 2D Tabulation, and 1D Space-Optimized Tabulation), complete with operational counters (call counts, array writes), assertion drivers, and differential oracle validation.

class KnapsackEngine:
    def __init__(self, weights, values, capacity):
        self.weights = weights
        self.values = values
        self.capacity = capacity
        self.n = len(weights)

    def solve_recursive(self):
        calls = [0]
        def recurse(i, w):
            calls[0] += 1
            if i == 0 or w == 0:
                return 0
            if self.weights[i - 1] > w:
                return recurse(i - 1, w)
            return max(recurse(i - 1, w), self.values[i - 1] + recurse(i - 1, w - self.weights[i - 1]))
        val = recurse(self.n, self.capacity)
        return val, calls[0]

    def solve_memoized(self):
        memo = {}
        calls = [0]
        def recurse(i, w):
            calls[0] += 1
            if i == 0 or w == 0:
                return 0
            if (i, w) in memo:
                return memo[(i, w)]
            if self.weights[i - 1] > w:
                res = recurse(i - 1, w)
            else:
                res = max(recurse(i - 1, w), self.values[i - 1] + recurse(i - 1, w - self.weights[i - 1]))
            memo[(i, w)] = res
            return res
        val = recurse(self.n, self.capacity)
        return val, calls[0]

    def solve_tabulated(self):
        dp = [[0] * (self.capacity + 1) for _ in range(self.n + 1)]
        writes = 0
        for i in range(1, self.n + 1):
            for w in range(1, self.capacity + 1):
                writes += 1
                if self.weights[i - 1] <= w:
                    dp[i][w] = max(dp[i - 1][w], self.values[i - 1] + dp[i - 1][w - self.weights[i - 1]])
                else:
                    dp[i][w] = dp[i - 1][w]
        return dp[self.n][self.capacity], writes

    def solve_space_optimized(self):
        dp = [0] * (self.capacity + 1)
        writes = 0
        for i in range(self.n):
            for w in range(self.capacity, self.weights[i] - 1, -1):
                writes += 1
                dp[w] = max(dp[w], self.values[i] + dp[w - self.weights[i]])
        return dp[self.capacity], writes

#include <iostream>
#include <vector>
#include <algorithm>
#include <cassert>

class KnapsackEngine {
private:
    std::vector<int> weights;
    std::vector<int> values;
    int capacity;
    int n;

public:
    KnapsackEngine(std::vector<int> w, std::vector<int> v, int cap)
        : weights(w), values(v), capacity(cap), n(w.size()) {}

    std::pair<int, int> solve_recursive() {
        int calls = 0;
        auto recurse = & -> int {
            calls++;
            if (i == 0 || w == 0) return 0;
            if (weights[i - 1] > w) return self(self, i - 1, w);
            return std::max(self(self, i - 1, w), values[i - 1] + self(self, i - 1, w - weights[i - 1]));
        };
        int val = recurse(recurse, n, capacity);
        return {val, calls};
    }

    std::pair<int, int> solve_memoized() {
        int calls = 0;
        std::vector<std::vector<int>> memo(n + 1, std::vector<int>(capacity + 1, -1));
        auto recurse = & -> int {
            calls++;
            if (i == 0 || w == 0) return 0;
            if (memo[i][w] != -1) return memo[i][w];
            if (weights[i - 1] > w) {
                memo[i][w] = self(self, i - 1, w);
            } else {
                memo[i][w] = std::max(self(self, i - 1, w), values[i - 1] + self(self, i - 1, w - weights[i - 1]));
            }
            return memo[i][w];
        };
        int val = recurse(recurse, n, capacity);
        return {val, calls};
    }

    std::pair<int, int> solve_tabulated() {
        std::vector<std::vector<int>> dp(n + 1, std::vector<int>(capacity + 1, 0));
        int writes = 0;
        for (int i = 1; i <= n; ++i) {
            for (int w = 1; w <= capacity; ++w) {
                writes++;
                if (weights[i - 1] <= w) {
                    dp[i][w] = std::max(dp[i - 1][w], values[i - 1] + dp[i - 1][w - weights[i - 1]]);
                } else {
                    dp[i][w] = dp[i - 1][w];
                }
            }
        }
        return {dp[n][capacity], writes};
    }

    std::pair<int, int> solve_space_optimized() {
        std::vector<int> dp(capacity + 1, 0);
        int writes = 0;
        for (int i = 0; i < n; ++i) {
            for (int w = capacity; w >= weights[i]; --w) {
                writes++;
                dp[w] = std::max(dp[w], values[i] + dp[w - weights[i]]);
            }
        }
        return {dp[capacity], writes};
    }
};

int main() {
    std::vector<int> weights = {2, 3, 4, 5};
    std::vector<int> values = {3, 4, 5, 6};
    int capacity = 5;

    KnapsackEngine engine(weights, values, capacity);
    auto [v_rec, c_rec] = engine.solve_recursive();
    auto [v_mem, c_mem] = engine.solve_memoized();
    auto [v_tab, w_tab] = engine.solve_tabulated();
    auto [v_opt, w_opt] = engine.solve_space_optimized();

    assert(v_rec == 7 && v_mem == 7 && v_tab == 7 && v_opt == 7);
    std::cout << "C++ DP Engine: All 4 paradigms validated successfully!\n";
    std::cout << "Results: Value=" << v_tab << " | Rec Calls=" << c_rec
              << ", Memo Calls=" << c_mem << ", Tab Writes=" << w_tab << ", Opt Writes=" << w_opt << "\n";
    return 0;
}

import java.util.Arrays;

public class DPWorkbookDemo {

    public static class KnapsackEngine {
        private final int[] weights;
        private final int[] values;
        private final int capacity;
        private final int n;

        public KnapsackEngine(int[] weights, int[] values, int capacity) {
            this.weights = weights;
            this.values = values;
            this.capacity = capacity;
            this.n = weights.length;
        }

        public int[] solveRecursive() {
            int[] calls = new int[1];
            int val = recurse(n, capacity, calls);
            return new int[]{val, calls[0]};
        }

        private int recurse(int i, int w, int[] calls) {
            calls[0]++;
            if (i == 0 || w == 0) return 0;
            if (weights[i - 1] > w) return recurse(i - 1, w, calls);
            return Math.max(recurse(i - 1, w, calls), values[i - 1] + recurse(i - 1, w - weights[i - 1], calls));
        }

        public int[] solveMemoized() {
            int[] calls = new int[1];
            int[][] memo = new int[n + 1][capacity + 1];
            for (int[] row : memo) Arrays.fill(row, -1);
            int val = recurseMemo(n, capacity, memo, calls);
            return new int[]{val, calls[0]};
        }

        private int recurseMemo(int i, int w, int[][] memo, int[] calls) {
            calls[0]++;
            if (i == 0 || w == 0) return 0;
            if (memo[i][w] != -1) return memo[i][w];
            if (weights[i - 1] > w) {
                memo[i][w] = recurseMemo(i - 1, w, memo, calls);
            } else {
                memo[i][w] = Math.max(recurseMemo(i - 1, w, memo, calls),
                                      values[i - 1] + recurseMemo(i - 1, w - weights[i - 1], memo, calls));
            }
            return memo[i][w];
        }

        public int[] solveTabulated() {
            int[][] dp = new int[n + 1][capacity + 1];
            int writes = 0;
            for (int i = 1; i <= n; i++) {
                for (int w = 1; w <= capacity; w++) {
                    writes++;
                    if (weights[i - 1] <= w) {
                        dp[i][w] = Math.max(dp[i - 1][w], values[i - 1] + dp[i - 1][w - weights[i - 1]);
                    } else {
                        dp[i][w] = dp[i - 1][w];
                    }
                }
            }
            return new int[]{dp[n][capacity], writes};
        }

        public int[] solveSpaceOptimized() {
            int[] dp = new int[capacity + 1];
            int writes = 0;
            for (int i = 0; i < n; i++) {
                for (int w = capacity; w >= weights[i]; w--) {
                    writes++;
                    dp[w] = Math.max(dp[w], values[i] + dp[w - weights[i]]);
                }
            }
            return new int[]{dp[capacity], writes};
        }
    }

    public static void main(String[] args) {
        int[] weights = {2, 3, 4, 5};
        int[] values = {3, 4, 5, 6};
        int capacity = 5;

        KnapsackEngine engine = new KnapsackEngine(weights, values, capacity);
        int[] rec = engine.solveRecursive();
        int[] mem = engine.solveMemoized();
        int[] tab = engine.solveTabulated();
        int[] opt = engine.solveSpaceOptimized();

        if (rec[0] != 7 || mem[0] != 7 || tab[0] != 7 || opt[0] != 7) {
            throw new AssertionError("DP Paradigm mismatch!");
        }

        System.out.println("Java DP Engine: All 4 paradigms validated successfully!");
        System.out.println("Results: Value=" + tab[0] + " | Rec Calls=" + rec[1]
                + ", Memo Calls=" + mem[1] + ", Tab Writes=" + tab[1] + ", Opt Writes=" + opt[1]);
    }
}

Correctness Testing Against a Reference Oracle

Automated correctness testing executes randomized problem instances against a slow, brute-force subset enumeration oracle ($O(2^N)$ exhaustive evaluation).

The case study below illustrates how the reference oracle verifier isolates a common state corruption bug in space-optimized rolling array DP implementations.

Testing Lab

Find the Bug

Scenario: A 1D space-optimized 0/1 Knapsack implementation returns corrupted, over-inflated objective values that match an Unbounded Knapsack problem rather than a 0/1 Knapsack.

Diagnostic Trace:

  1. Oracle Input: The test suite inputs an item with weight $w = 2$, value $v = 3$, and total capacity $W = 5$.
  2. Behavior Observed: The 1D space-optimized solver produces an objective value of $6$ instead of $3$.
  3. Audit Inspection: The inner capacity loop was implemented iterating left-to-right (for w in range(weights[i], capacity + 1)) instead of right-to-left (for w in range(capacity, weights[i] - 1, -1)).
  4. Failure Point: In left-to-right iteration, dp[2] is updated to $3$. When the loop reaches w = 4, dp[4] reads the already updated dp[2] value ($3$), adding value $v = 3$ again to yield $6$. Item $i$ is selected multiple times!

Remediation: Traverse capacity right-to-left when using a single rolling 1D buffer so dp[w - weights[i]] references state values from the previous item iteration ($i - 1$) rather than the current row.
