Project Brief and API Contract

The External-Memory B+ Tree / Sorting Project provides a unified secondary-storage engine designed around the Aggarwal-Vitter External Memory Model. In systems where datasets exceed main memory capacity ($N \gg M$), performance is governed not by CPU instruction counts, but by block transfers ($I/O$ operations) between high-latency secondary storage (disks/SSDs) and fast main memory (RAM). This project implements two fundamental external-memory algorithms: a Disk-Page B+ Tree for indexed point and range queries, and an External $k$-Way Merge Sort for large-scale dataset ordering.

The public interface isolates disk interaction through a DiskManager and BufferPool abstraction layer. Rather than measuring wall-clock execution time—which fluctuates due to OS caching and hardware noise—every operation is evaluated directly by its total block reads and block writes ($I/O$ count). All data structures manipulate fixed-size pages of size $B$, ensuring that theoretical $I/O$ bounds ($O(\log_B N)$ for B+ Tree lookups and $O(\frac{N}{B} \log_{M/B} \frac{N}{B})$ for external sorting) are empirically verified.

External-Memory Engine Contract: The engine exposes standard relational and sorting operations (insert, search, range_query, external_sort) over a simulated or file-backed page storage layer. Success criteria require 100% correctness matching an in-memory reference oracle, strict compliance with $B$-element page constraints, and exact logarithmic/super-linear $I/O$ transfer bounds without memory pin leaks.

Architecture and Data Flow

The system is structured as a layered architecture that decouples page-level storage management from high-level indexing and sorting logic.

The architecture comprises five interacting components:

  1. Disk Storage Simulator (DiskManager): Manages block-aligned persistent storage, assigning unique Page IDs and logging discrete read_block and write_block transfer operations.
  2. Buffer Pool Manager (BufferPool): Implements an LRU frame cache in main memory ($M$ bytes capacity) with explicit page pinning, unpinning, and dirty-bit flushing.
  3. Disk-Page B+ Tree Engine: Constructs an $M$-way search tree where internal and leaf nodes occupy single disk pages. Leaves form a doubly-linked list for sequential disk scans.
  4. External $k$-Way Merge Sort Engine: Performs run generation by sorting $M$-sized memory chunks in RAM, followed by multi-way merging using a min-heap over $k = \lfloor M/B \rfloor - 1$ active input page buffers.
  5. Reference Oracle & Telemetry Collector: Compares external engine outputs against an in-memory array/map oracle while recording total $I/O$ transfers.

import heapq

class DiskManager:
    def __init__(self, block_size=4):
        self.block_size = block_size
        self.pages = {}
        self.read_count = 0
        self.write_count = 0
        self.next_page_id = 0

    def allocate_page(self, data):
        pid = self.next_page_id
        self.next_page_id += 1
        self.write_page(pid, data)
        return pid

    def read_page(self, pid):
        self.read_count += 1
        return list(self.pages[pid])

    def write_page(self, pid, data):
        if len(data) > self.block_size:
            raise ValueError(f"Data size {len(data)} exceeds block size {self.block_size}")
        self.write_count += 1
        self.pages[pid] = list(data)


class ExternalMergeSort:
    def __init__(self, disk, memory_blocks=3):
        self.disk = disk
        self.memory_capacity = memory_blocks * disk.block_size

    def sort(self, input_data):
        if not input_data:
            return []

        # Step 1: Run Generation
        runs = []
        for i in range(0, len(input_data), self.memory_capacity):
            chunk = sorted(input_data[i\:i + self.memory_capacity])
            run_pids = []
            for j in range(0, len(chunk), self.disk.block_size):
                block = chunk[j\:j + self.disk.block_size]
                run_pids.append(self.disk.allocate_page(block))
            runs.append(run_pids)

        # Step 2: k-Way Merging
        while len(runs) > 1:
            next_runs = []
            for i in range(0, len(runs), 2):
                if i + 1 < len(runs):
                    merged_run = self._merge_two_runs(runs[i], runs[i + 1])
                    next_runs.append(merged_run)
                else:
                    next_runs.append(runs[i])
            runs = next_runs

        # Read back final sorted result
        sorted_result = []
        for pid in runs[0]:
            sorted_result.extend(self.disk.read_page(pid))
        return sorted_result

    def _merge_two_runs(self, run1, run2):
        merged_pids = []
        p1_idx, p2_idx = 0, 0
        b1 = self.disk.read_page(run1[p1_idx]) if run1 else []
        b2 = self.disk.read_page(run2[p2_idx]) if run2 else []
        i1, i2 = 0, 0
        out_buffer = []

        while i1 < len(b1) or i2 < len(b2):
            if i1 >= len(b1) and p1_idx + 1 < len(run1):
                p1_idx += 1
                b1 = self.disk.read_page(run1[p1_idx])
                i1 = 0
            if i2 >= len(b2) and p2_idx + 1 < len(run2):
                p2_idx += 1
                b2 = self.disk.read_page(run2[p2_idx])
                i2 = 0

            v1 = b1[i1] if i1 < len(b1) else float('inf')
            v2 = b2[i2] if i2 < len(b2) else float('inf')

            if v1 <= v2 and v1 != float('inf'):
                out_buffer.append(v1)
                i1 += 1
            elif v2 != float('inf'):
                out_buffer.append(v2)
                i2 += 1

            if len(out_buffer) == self.disk.block_size:
                merged_pids.append(self.disk.allocate_page(out_buffer))
                out_buffer = []

        if out_buffer:
            merged_pids.append(self.disk.allocate_page(out_buffer))

        return merged_pids

class DiskManager {
public:
    int block_size;
    std::map<int, std::vector<int>> pages;
    int read_count = 0;
    int write_count = 0;
    int next_page_id = 0;

    explicit DiskManager(int bs = 4) : block_size(bs) {}

    int allocate_page(const std::vector<int>& data) {
        int pid = next_page_id++;
        write_page(pid, data);
        return pid;
    }

    std::vector<int> read_page(int pid) {
        read_count++;
        return pages[pid];
    }

    void write_page(int pid, const std::vector<int>& data) {
        assert((int)data.size() <= block_size);
        write_count++;
        pages[pid] = data;
    }
};

class ExternalMergeSort {
    DiskManager& disk;
    int memory_capacity;

public:
    ExternalMergeSort(DiskManager& dm, int memory_blocks = 3)
        : disk(dm), memory_capacity(memory_blocks * dm.block_size) {}

    std::vector<int> sort(const std::vector<int>& input_data) {
        if (input_data.empty()) return {};

        std::vector<std::vector<int>> runs;
        for (size_t i = 0; i < input_data.size(); i += memory_capacity) {
            size_t end = std::min(i + memory_capacity, input_data.size());
            std::vector<int> chunk(input_data.begin() + i, input_data.begin() + end);
            std::sort(chunk.begin(), chunk.end());

            std::vector<int> run_pids;
            for (size_t j = 0; j < chunk.size(); j += disk.block_size) {
                size_t bend = std::min(j + disk.block_size, chunk.size());
                std::vector<int> block(chunk.begin() + j, chunk.begin() + bend);
                run_pids.push_back(disk.allocate_page(block));
            }
            runs.push_back(run_pids);
        }

        while (runs.size() > 1) {
            std::vector<std::vector<int>> next_runs;
            for (size_t i = 0; i < runs.size(); i += 2) {
                if (i + 1 < runs.size()) {
                    next_runs.push_back(merge_two_runs(runs[i], runs[i + 1]));
                } else {
                    next_runs.push_back(runs[i]);
                }
            }
            runs = next_runs;
        }

        std::vector<int> sorted_result;
        for (int pid : runs[0]) {
            std::vector<int> block = disk.read_page(pid);
            sorted_result.insert(sorted_result.end(), block.begin(), block.end());
        }
        return sorted_result;
    }

private:
    std::vector<int> merge_two_runs(const std::vector<int>& run1, const std::vector<int>& run2) {
        std::vector<int> merged_pids;
        size_t p1_idx = 0, p2_idx = 0;
        std::vector<int> b1 = !run1.empty() ? disk.read_page(run1[p1_idx]) : std::vector<int>();
        std::vector<int> b2 = !run2.empty() ? disk.read_page(run2[p2_idx]) : std::vector<int>();
        size_t i1 = 0, i2 = 0;
        std::vector<int> out_buffer;

        while (i1 < b1.size() || i2 < b2.size()) {
            if (i1 >= b1.size() && p1_idx + 1 < run1.size()) {
                b1 = disk.read_page(run1[++p1_idx]);
                i1 = 0;
            }
            if (i2 >= b2.size() && p2_idx + 1 < run2.size()) {
                b2 = disk.read_page(run2[++p2_idx]);
                i2 = 0;
            }

            int v1 = (i1 < b1.size()) ? b1[i1] : INT_MAX;
            int v2 = (i2 < b2.size()) ? b2[i2] : INT_MAX;

            if (v1 <= v2 && v1 != INT_MAX) {
                out_buffer.push_back(v1);
                i1++;
            } else if (v2 != INT_MAX) {
                out_buffer.push_back(v2);
                i2++;
            }

            if ((int)out_buffer.size() == disk.block_size) {
                merged_pids.push_back(disk.allocate_page(out_buffer));
                out_buffer.clear();
            }
        }
        if (!out_buffer.empty()) {
            merged_pids.push_back(disk.allocate_page(out_buffer));
        }
        return merged_pids;
    }
};

import java.util.*;

public class Main {

    public static class DiskManager {
        public final int blockSize;
        public final Map<Integer, List<Integer>> pages = new HashMap<>();
        public int readCount = 0;
        public int writeCount = 0;
        private int nextPageId = 0;

        public DiskManager(int blockSize) {
            this.blockSize = blockSize;
        }

        public int allocatePage(List<Integer> data) {
            int pid = nextPageId++;
            writePage(pid, data);
            return pid;
        }

        public List<Integer> readPage(int pid) {
            readCount++;
            return new ArrayList<>(pages.get(pid));
        }

        public void writePage(int pid, List<Integer> data) {
            if (data.size() > blockSize) throw new IllegalArgumentException("Exceeds block size");
            writeCount++;
            pages.put(pid, new ArrayList<>(data));
        }
    }

    public static class ExternalMergeSort {
        private final DiskManager disk;
        private final int memoryCapacity;

        public ExternalMergeSort(DiskManager dm, int memoryBlocks) {
            this.disk = dm;
            this.memoryCapacity = memoryBlocks * dm.blockSize;
        }

        public List<Integer> sort(List<Integer> inputData) {
            if (inputData.isEmpty()) return Collections.emptyList();

            List<List<Integer>> runs = new ArrayList<>();
            for (int i = 0; i < inputData.size(); i += memoryCapacity) {
                int end = Math.min(i + memoryCapacity, inputData.size());
                List<Integer> chunk = new ArrayList<>(inputData.subList(i, end));
                Collections.sort(chunk);

                List<Integer> runPids = new ArrayList<>();
                for (int j = 0; j < chunk.size(); j += disk.blockSize) {
                    int bend = Math.min(j + disk.blockSize, chunk.size());
                    runPids.add(disk.allocatePage(new ArrayList<>(chunk.subList(j, bend))));
                }
                runs.add(runPids);
            }

            while (runs.size() > 1) {
                List<List<Integer>> nextRuns = new ArrayList<>();
                for (int i = 0; i < runs.size(); i += 2) {
                    if (i + 1 < runs.size()) {
                        nextRuns.add(mergeTwoRuns(runs.get(i), runs.get(i + 1)));
                    } else {
                        nextRuns.add(runs.get(i));
                    }
                }
                runs = nextRuns;
            }

            List<Integer> sortedResult = new ArrayList<>();
            for (int pid : runs.get(0)) {
                sortedResult.addAll(disk.readPage(pid));
            }
            return sortedResult;
        }

        private List<Integer> mergeTwoRuns(List<Integer> run1, List<Integer> run2) {
            List<Integer> mergedPids = new ArrayList<>();
            int p1Idx = 0, p2Idx = 0;
            List<Integer> b1 = !run1.isEmpty() ? disk.readPage(run1.get(p1Idx)) : Collections.emptyList();
            List<Integer> b2 = !run2.isEmpty() ? disk.readPage(run2.get(p2Idx)) : Collections.emptyList();
            int i1 = 0, i2 = 0;
            List<Integer> outBuffer = new ArrayList<>();

            while (i1 < b1.size() || i2 < b2.size()) {
                if (i1 >= b1.size() && p1Idx + 1 < run1.size()) {
                    b1 = disk.readPage(run1.get(++p1Idx));
                    i1 = 0;
                }
                if (i2 >= b2.size() && p2Idx + 1 < run2.size()) {
                    b2 = disk.readPage(run2.get(++p2Idx));
                    i2 = 0;
                }

                int v1 = (i1 < b1.size()) ? b1.get(i1) : Integer.MAX_VALUE;
                int v2 = (i2 < b2.size()) ? b2.get(i2) : Integer.MAX_VALUE;

                if (v1 <= v2 && v1 != Integer.MAX_VALUE) {
                    outBuffer.add(v1);
                    i1++;
                } else if (v2 != Integer.MAX_VALUE) {
                    outBuffer.add(v2);
                    i2++;
                }

                if (outBuffer.size() == disk.blockSize) {
                    mergedPids.add(disk.allocatePage(outBuffer));
                    outBuffer = new ArrayList<>();
                }
            }
            if (!outBuffer.isEmpty()) {
                mergedPids.add(disk.allocatePage(outBuffer));
            }
            return mergedPids;
        }
    }

    public static void main(String[] args) {
        DiskManager disk = new DiskManager(4);
        ExternalMergeSort sorter = new ExternalMergeSort(disk, 2);

        List<Integer> rawData = Arrays.asList(25, 12, 3, 40, 7, 19, 1, 88, 15, 6, 4, 33, 50, 2, 11);
        List<Integer> expected = new ArrayList<>(rawData);
        Collections.sort(expected);

        List<Integer> sortedData = sorter.sort(rawData);
        if (!sortedData.equals(expected)) {
            throw new AssertionError("Output mismatch!");
        }

        System.out.println("Java External-Memory Engine: All tests passed successfully.");
        System.out.println("Block Reads: " + disk.readCount + ", Block Writes: " + disk.writeCount);
    }
}

Correctness Testing Against a Reference Oracle

Verification uses randomized data inputs executed concurrently against an in-memory reference oracle (std::map or sorted arrays).

The diagnostic card below isolates a pin leak bug during B+ tree leaf node splitting.

Testing Lab

Find the Bug

Scenario: A B+ Tree implementation experiences buffer pool exhaustion and crashes with a "No Free Buffer Frames" exception during large sequential insertions, despite memory limits being respected.

Diagnostic Trace:

  1. Oracle Input: The test suite inserts 10,000 ascending integer keys into a B+ Tree with buffer capacity $M = 10$ frames.
  2. Behavior Observed: The tree completes 256 insertions and then throws a frame pool exhaustion exception.
  3. Audit Inspection: Inspection of the split_child(parent, index, child) routine shows that the original child page frame was requested via buffer_pool.get_page(child_pid) but never released via buffer_pool.unpin_page(child_pid, is_dirty=True).
  4. Failure Point: Unpinned page frame counters reached zero because child pages remained pinned in RAM during split propagation, leaking buffer pool slots on every node split.

Remediation: Enforce strict RAII or try/finally blocks around page pins. Always pair get_page(pid) with a corresponding unpin_page(pid, dirty_flag) once node key adjustments finish.

Extensions and Stretch Goals

To evolve the external memory engine toward enterprise database production standards, consider the following engineering milestones:

Extension Roadmap & Engineering Targets:

  1. Tier 1 (Write-Ahead Logging & ARIES Recovery): Implement an append-only WAL log with write sequence numbers (LSN) to guarantee ACID durability across unbuffered page flushes.
  2. Tier 2 (Concurrent B-Link Trees): Add Lehmann-Yao right-sibling pointers and node lock coupling to enable latch-free concurrent reader/writer tree traversals.
  3. Tier 3 (Prefix & Suffix Key Compression): Implement variable-length key encoding and delta compression within B+ Tree internal pages to increase node fanout $B$ by up to $3\times$.
